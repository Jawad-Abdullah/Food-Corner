Project summary

Food Corner is a responsive single-page restaurant website built with HTML and CSS. It contains a navigation header, welcome area, four menu items with prices, an about section, an order request form and a footer. The CSS workshop explanations and examples are included in this report.

CSS Workshop Examples

These short examples document the CSS concepts used in the lab.

Margin collapsing

.first { margin-bottom: 28px; }
  .second { margin-top: 18px; }

When these normal block elements are stacked vertically, their adjoining margins collapse. The visible gap is 28px, not 46px. Horizontal margins do not collapse in this way, and padding or a border between elements can prevent adjoining vertical margins.

Overflow

.visible { overflow: visible; }
  .hidden { overflow: hidden; }
  .scroll { overflow: scroll; }
  .example-box { height: 56px; }

Use content taller than the fixed-height box to observe visible overflow, clipped content, and scrolling content.

Width, height and display

.responsive-box {
    width: 100%;
    height: 140px;
    min-width: 170px;
    max-width: 420px;
    min-height: 120px;
    max-height: 180px;
  }
  .block-example { display: block; }
  .inline-example { display: inline; }
  .inline-block-example { display: inline-block; }
  .hidden-example { display: none; }

The minimum and maximum constraints limit the box as its available space changes. The display values control whether elements start on a new line, flow with text, keep box dimensions inline, or are removed from layout.

Cascade, specificity and inheritance

body { color: #61716a; }
  .note { color: #bd4f37; }
  .note { color: #245c50; }
  section .note { color: #183d37; }

The body color is inherited unless a child has its own color. Of the two equally specific .note rules, the later one wins by source order. The more specific section .note selector overrides both.

Margin collapsing observation

When two normal block elements are stacked vertically, their adjoining vertical margins can collapse into one margin. The resulting space is the larger of the two margins, not their total. In this demonstration, the first block has a 28px bottom margin and the second has an 18px top margin. The visible gap is 28px. Horizontal margins do not collapse in this way, and padding or a border between elements can prevent vertical margins from adjoining.
