Project summary

Food Corner is a responsive single-page restaurant website built with HTML and CSS. It contains a navigation header, welcome area, four menu items with prices, an about section, a contact form and a footer. A CSS workshop section on the page makes the required layout and styling demonstrations visible.

CSS concepts demonstrated

ConceptWhere it appears
Inline, internal and external CSSThe welcome sticker has an inline style in index.html; the head contains internal rules for the report note and margin demo; style.css contains the site's main design.
SelectorsElement (body), class (.food-card), ID (#home), attribute (input[type="email"]), grouping (h1, h2, h3, p), and descendant (.food-card .food-content h3) selectors are in style.css.
Pseudo-classes and pseudo-elementsNavigation and order buttons use :hover. The first menu card uses :first-child. Workshop headings use ::before and ::after.
Cascade, specificity and inheritanceThe body supplies inherited font and color. The .lab-panel .lab-note rule overrides the less-specific .lab-note rule. Repeated .cascade-note rules demonstrate source order; .css-lab .cascade-note wins by specificity.
Fonts, text and colorsFont family, size, weight and italic style; alignment, decoration and line height; named, HEX and RGB colors are used in the page styles.
Backgrounds, box model and cardsMenu imagery uses background-image, repeat, position and size. Cards use width, height, padding, borders, margin via the grid gap, border radius, shadow and border-box sizing.
Margin collapsingThe two workshop blocks have adjoining vertical margins. Their margins collapse, so the gap is the larger margin rather than their sum.
Constraints and overflowThe size-constraints example uses width, height, min-width, max-width, min-height and max-height. Three fixed-height boxes show visible, hidden and scroll overflow.
Display valuesThe workshop shows block, inline, inline-block and none. Navigation anchors are inline-block; the hidden sample is removed from layout with display:none.

Margin collapsing observation

When two normal block elements are stacked vertically, their adjoining vertical margins can collapse into one margin. The resulting space is the larger of the two margins, not their total. In this demonstration, the first block has a 28px bottom margin and the second has an 18px top margin. The visible gap is 28px. Horizontal margins do not collapse in this way, and padding or a border between elements can prevent vertical margins from adjoining.
