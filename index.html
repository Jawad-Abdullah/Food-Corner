Margin collapsing

These two blocks have adjoining vertical margins. The gap is 28px, not 46px.

First block · margin-bottom: 28px
Second block · margin-top: 18px

Adjacent vertical margins between normal block elements collapse to the larger margin. Here, 28px wins over 18px.

Overflow behavior

Each fixed-height box contains more text than fits.

visible Extra text stays visible beyond this 56px box. The content is not clipped.
hidden Extra text is clipped at the edge of this 56px box.
scroll Extra text can be reached by scrolling inside this 56px box.

Resize the window: this box has width, height and min/max limits.
